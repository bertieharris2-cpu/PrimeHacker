# PRIMENET

A maths game about factors and primes, with a hacker theme. Students work out a bank's blueprint using factor pairs, then break into its vault using prime factors.

These are the original files, imported as they were before any changes.

## Layout

| Folder | What's in it |
|---|---|
| root | Start screens: `launcher.html` (opened by `start-primenet.bat`), `demo.html` and `index.html` (the hub) |
| `modules/` | The linked games: Factor Vault → Vault Grid → Blueprint → Prime Hack, plus `bank.js` (wallet) and the sound notes |
| `drafts/` | Earlier versions and unconnected pieces: Prime Frequency Scan, older Factor Vault and Prime Hack versions, the Menu UI design |
| `docs/` | Design notes: `Style_Root.txt` (colours and fonts) and `Segment_Instructions.docx` (finale effects) |

Open `launcher.html` in a browser to play. The Blueprint's 3D view loads Three.js from unpkg.com, so it needs an internet connection.
